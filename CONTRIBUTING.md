# Contributing to superglue

This repository is deprecated and no longer accepts contributions. We're not reviewing new issues or pull requests here.

superglue continues as a hosted product at [superglue.ai](https://superglue.ai). If you found a bug or have a feature idea, we'd still like to hear it: [book a call](https://cal.com/superglue/superglue-demo) or sign up at [app.superglue.cloud](https://app.superglue.cloud) and reach out from there.

Thanks to everyone who opened issues, sent PRs and helped shape superglue while it lived here.
